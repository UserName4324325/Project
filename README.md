Как запустить проект.

Сначала скачайте git и клонируете репозиторий (Посмотрите на ютубе как это делается там 5 мин)
Установите Docker desktop

Перейдите в папку с docker-compose.yml (..../Project/Project)

выполните команду 
docker compose up --build

сайт находится по адресу
http://localhost:3000/
